## 项目背景

我希望把个人主页做成一个真正可持续更新的内容空间，而不是只展示几条资料的 landing page。

## 设计目标

- 在浅色与深色主题下都保持统一气质。
- 用卡片化语言组织复杂信息，但避免 dashboard 化。
- 通过更透气的间距，让阅读体验更稳定。

## 技术取舍

整个站点优先使用静态渲染，交互只放在必要的局部，例如主题切换、移动端导航和少量 hover 反馈。这样能把维护成本压低，也更适合 GitHub Pages。
